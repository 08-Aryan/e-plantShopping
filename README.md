# e-plantShopping

e-plantShopping is a React-based web application for browsing and shopping plants online. The application allows users to explore different plants, add items to a shopping cart, and manage their shopping experience through a clean and interactive interface.

## Features

- Browse a variety of plants
- Add and remove items from cart
- Responsive user interface
- Built using React and Vite
- Component-based project structure

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## Installation

Install dependencies:

```bash
npm install

Build the project:

```bash
npm run build
